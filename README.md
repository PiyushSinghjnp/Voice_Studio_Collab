# Voice Studio on Google Colab

This repository is intended to help you use Voice Studio in a collaborative Google Colab environment.

## Getting started

1. Open the Voice Studio notebook from this repository in Google Colab.
2. Connect to a runtime.
3. Run the notebook cells from top to bottom, following any prompts to install dependencies or provide input files.
4. Upload or select your audio files when prompted, then use the notebook's available tools to work with them.
5. Save or download your results before disconnecting the runtime.
